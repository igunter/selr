## BUILD

Run `composer setup` to install all dependencies and build the project.

Run `composer dev` to run the project in development mode.

Run `composer test` to run the project in test mode.

Run `composer prod` to run the project in production mode.


## ABOUT

This is an online store with a full administration section for product, category, order, user and role management.

I have built this project fully by hand with only asking Claude to validate the codebase to point out any issues.

This project is built using [Laravel](https://laravel.com/).


## FEATURES

The project has the following features:

- [ ] Authentication
- [ ] User management
- [ ] Role management
- [ ] Two-factor authentication for administration
- [ ] Product management
- [ ] Category management
- [ ] Order management
- [ ] Cart management

- [ ] Payment management
- [ ] Shipping management
